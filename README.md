## Descrição

O **BNCC Connect** é uma plataforma web colaborativa desenvolvida para auxiliar professores da Educação Básica na implementação da BNCC Computação. A plataforma permite o compartilhamento e a organização de atividades pedagógicas alinhadas às competências e habilidades da BNCC, facilitando o planejamento de aulas, incentivando a colaboração entre educadores e promovendo a disseminação de boas práticas no ensino de Computação.

## Sobre o projeto

Este projeto foi desenvolvido como parte da disciplina de **Engenharia de Software Aplicada (ESA)**, no período **2026.1**, sob orientação da Prof.ª Dr.ª *Juliana Saraiva*.
